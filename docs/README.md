## 🚀 Quick Start Guide

### New Users
1. Read the [User Manual](USER_MANUAL.md) introduction and getting started sections
2. Follow the installation instructions in the main [README](../README.md)
3. Configure your API key using the [Settings Guide](SETTINGS_CONFIGURATION_GUIDE.md)
4. Try basic commands and explore the interface

3. Configure voice settings in the AI tab
4. Practice with simple voice commands

### Advanced Users
